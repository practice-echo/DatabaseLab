# 基于栈的算术表达式求值 (Infix Expression Evaluator)

## 一、 项目简介

本项目是《数据结构》实验二的完整实现。项目**直接使用中缀表达式**（不转换为后缀表达式）进行求值。支持加（`+`）、减（`-`）、乘（`*`）、除（`/`）、括号（`(`、`)`），支持多位数（拼数功能），并以 `=` 作为表达式结束符。支持多组数据连续输入，单独输入一个 `=` 时程序退出。

## 二、 目录结构

text

```
├── main.c           # 主程序：负责输入输出处理与多组数据循环
├── stack.h          # 栈的定义：声明操作数栈(OPND)和运算符栈(OPTR)的结构与接口

├── expression.h     # 算法声明：声明中缀表达式求值核心函数

└── README.md        # 项目说明文档（本文件）
```

## 三、 核心逻辑与算法

### 1. 数据结构设计

为了实现求值，项目设置了两个独立的工作栈：

- **OPND (操作数栈)**：用于存储运算数及中间计算结果（`int` 类型）。
- **OPTR (运算符栈)**：用于存储运算符（`char` 类型）。栈底初始化为 `=`，用于判断表达式是否结束。

### 2. 算符优先关系表

根据严蔚敏《数据结构》表2.1构建了一个二维数组。

- `top < c`：当前读入的运算符优先级高，将 `c` 压入 `OPTR`。
- `top = c`：优先级相等，通常代表遇到了 `(` 和 `)` 或者开头的 `=` 和结尾的 `=`，直接弹出 `OPTR` 栈顶元素（丢弃括号）。
- `top > c`：栈顶运算符优先级高，可以开始计算，弹出 `OPTR` 一个运算符和 `OPND` 两个操作数，计算后结果压回 `OPND`。

### 3. 关键算法细节

- **拼数功能**：实验指导书特别强调算法3.22缺少多位数支持。本项目在读入字符时，若遇到数字字符，会使用 `while` 循环继续向后读取相邻数字，通过 `num = num * 10 + (c - '0')` 拼接为真实整数后，再入操作数栈。
- **操作数出栈顺序**：当触发计算时，先出栈的必定是**右操作数**（`b`），后出栈的必定是**左操作数**（`a`），这保证了减法和除法的计算顺序绝对正确（如 `a - b` 或 `a / b`）。
- **结束条件**：将 `=` 视同于教材中的 `#`。当栈顶元素和当前读入字符均为 `=` 时，求值结束，此时 `OPND` 栈顶元素即为最终结果。

## 四、 各模块代码功能解析

### 1. `stack.h` & `stack.c` (基础工具层)

提供纯粹的容器功能，不涉及任何业务逻辑。

- **OpndStack (操作数栈)**：初始化、判空、压入 `int`、弹出 `int`、读取栈顶 `int`。
- **OptrStack (运算符栈)**：初始化、判空、压入 `char`、弹出 `char`、读取栈顶 `char`。

### 2. `expression.h` & `expression.c` (核心算法层)

这是整个项目的“大脑”，隐藏了所有复杂的业务逻辑。

- `getIndex(char theta)`：将运算符映射为优先级二维数组的行列索引（0-6）。
- `getPriority(char theta1, char theta2)`：查询二维数组，返回 `>`、`<` 或 `=`。
- `Operate(int a, char theta, int b)`：执行基础的二元算术运算。
- `EvaluateExpression(const char *expr)`：**核心求值引擎**。接收一个字符串，内部自动完成初始化、遍历字符串、处理空格、拼装多位数、比较优先级、计算结果并压栈，最后返回最终整型结果。

### 3. `main.c` (用户界面层)

保持极致的简洁，只负责 I/O：

1. 使用 `fgets` 循环读取每一行输入。
2. 去除 `fgets` 附带的换行符。
3. 判断如果当前行仅为 `=`，则 `break` 结束程序。
4. 否则调用 `EvaluateExpression(expr)` 并将结果 `printf` 输出。

## 五、 编译与运行

### 编译指令

在终端中，确保所有文件在同一目录下，使用 `gcc` 进行联合编译：

bash

```
gcc main.c stack.c expression.c -o calc
```



### 运行程序

bash

```
./calc
```



### 测试样例

输入：

text

```
2 + 2 =
20*(4 - 2) =
=
```



输出：

text

```
4
40
```







## 代码的结构

1. **`stack.h` / `stack.c`**：基础工具，只负责存数据和取数据。
2. **`expression.h` / `expression.c`**：核心算法模块。把优先级表、拼数功能、出栈计算等全部隐藏在这个模块里面。
3. **`main.c`**：界面层。
