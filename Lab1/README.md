### 1、图书表的创建和输出

输入一堆图书，读到 `0 0 0` 就停止输入； 输出：先输出一共有多少本书，再逐行打印每本书，价格保留 2 位小数.

**输入示例**

9787302257646 程序设计基础 25.00
9787302164340 程序设计基础(第2 版) 20.00
9787302219972 单片机技术及应用 32.00
9787302203513 单片机原理与应用技术 26.00
9787810827430 工业计算机控制技术--原理与应用 29.00
9787811234923 歇编语言程序设计教程 21.00
0 0 0

### 2、图书价格批量修改

1. 先算出所有书的**平均价格**
2. 价格＜均价 → 涨价 20%
3. 价格≥均价 → 涨价 10%
4. 输出：第一行均价，第二行图书总数，再输出改完价格的全部图书

**输入**

9787302257646 程序设计基础 25.00
9787302164340 程序设计基础(第2 版) 20.00
9787302219972 单片机技术及应用 32.00

9787811234923 歇编语言程序设计教程 21.00
0 0 0

25.50

### 4、新书入库（插入）

建好图书表之后，输入一个**位置序号**，把新书插到这个位置上

- 位置合法：插入成功，输出新表（先输出总数，再全部图书）
- 位置非法（比如一共 6 本书，你要插在第 10 位）：输出 `抱歉，入库位置非法!`

> ⚠️ 这里的序号是**从 1 开始计数**（不是数组 0 下标！样例里输入 2，插到第 2 个位置）

**输入样例**

9787302257646 程序设计基础 25.00
